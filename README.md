Entry for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551) (pot $35, 20 paid places).

`main.py` (Python 3.13, standard library only) writes one one-line joke about working beside an AI coding agent to `/output/entry.txt`: asked for one button, the agent shipped a settings page, a plugin system, and a bug that only appears on stage. The house AI judge compares entries two at a time and ranks them by how often it picks them.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
